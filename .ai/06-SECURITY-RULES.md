# Security Rules

- Default deny for authorization.
- Tenant isolation is mandatory in queries, jobs, caches, events, and storage paths.
- Credentials are encrypted/secret-managed and referenced by ID; never log secret values.
- Webhooks require signature verification where available, replay protection where feasible, and idempotency.
- Sensitive actions produce immutable audit events.
- RBAC uses granular permissions such as `campaign.send`, `provider.credentials.manage`, `ai.approve`.
- Input validation occurs at trust boundaries.
- HTML/template rendering treats user content as untrusted and uses a safe sanitization/rendering policy.
- Unsubscribe, consent, suppression, bounce, and complaint controls cannot be bypassed by AI or routing logic.
- No production connector generated by AI becomes active without required tests/review gates.
- Dependency and secret scanning must be enabled when application code is introduced.
- Security-impacting architecture changes require ADR and tests.
