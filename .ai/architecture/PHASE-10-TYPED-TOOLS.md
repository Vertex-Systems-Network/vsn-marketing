# TASK-0057 typed output and tool boundary

The bounded schema dialect supports only strict objects (no extra keys), lists with explicit limits, UTF-8 sanitized strings, enums, bounded integers and booleans. Unsupported keywords deny rather than silently weaken a schema. Application-selected schema/version, authenticated workspace and known reference set govern proposal validation. Non-complete provider statuses never release a proposal. The gateway defaults to withholding output. An explicitly constructed scoped validator binds the context hash, schema and known references; only its validated proposal envelope can be returned. It cannot execute a tool.

Tool execution is separately configured with the canonical tool registry, typed argument/result schemas, version, effect, permission and handler. Permission and approval services are trusted server dependencies. Model fields cannot provide them. Unknown tools/effects/permissions, risk downgrade, absent handler and malformed arguments deny before invocation. All writes require independently verified argument/actor/scope-bound approval plus reversible preflight/postconditions and rollback. Production/external tool handlers are not installed. Runtime registry configuration is server-owned; it is not a client request field.

Core durable idempotency stores a fingerprint of actor, workspace, brand, tool/version and arguments. Replays recheck permission and approval and reject changed fingerprints. Audit records hashes and identifiers, not raw arguments, model output or exceptions. Handler errors are normalized before entering the core audit path. A rollback failure explicitly requires operator recovery; this path cannot claim atomic remote effects or automatic recovery of an external provider.

No dependency, migration or external network integration is introduced. CI runs the locked framework feature/architecture/static/security and PostgreSQL suites. Local standalone schema tests are not a substitute for those checks. Future concrete tools must add their own consent/suppression/quota and external idempotency contracts before activation.
