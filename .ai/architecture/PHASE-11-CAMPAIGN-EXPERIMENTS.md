# Phase 11 campaign matrix — TASK-0064

This is an offline, workspace scoped candidate and evidence admission contract. An experiment draft binds to one canonical campaign snapshot, its immutable plan hash, and a complete bounded Cartesian product of content version, UTC candidate time and audience definition version. Every non-holdout arm belongs to the same assignment unit and plan. All referenced content and audience versions must exist in that workspace. The control content matches the pinned snapshot. The matrix hash and snapshot hash are checked on candidate and outcome reads.

Candidate resolution rechecks eligibility, consent and suppression through the caller supplied `ExperimentEligibility`, and delegates sticky allocation and layer exclusion to TASK-0063. A holdout returns no candidate. This service does not evaluate the audience definition, schedule an attempt, select a provider, render content, or record its own exposure. The returned reference is a scoped treatment claim for a separately authorized witness. Without a real eligibility adapter, segmentation evaluation and trusted exposure verifier, this service cannot be used to claim live delivery.

Outcome admission persists an `admitted` or `quarantined` record. It requires an earlier TASK-0063 witnessed exposure for the same assignment, binding reference and variant; missing exposure, mismatched treatment and crossover are quarantined. Repeated event references must carry identical provenance. An approving actor can stop the binding, which denies new candidates and retains all assignments, exposures and outcomes. Rollback of nonempty evidence tables is deliberately refused. There is no conversion metric, lift estimate, sequential decision or winner selection in this task.

Verification: focused feature tests cover deterministic replay, missing exposure, mismatch, stop, suppressed unit and foreign workspace. The TASK-0063 PostgreSQL fork contention test remains the concurrent assignment gate on the exact PR head. The offline test witness is deliberately synthetic; it proves ordering rules, not real exposure.
