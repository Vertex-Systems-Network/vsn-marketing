# ADR-0001 — Repository-native AI continuity

Status: ACCEPTED

## Decision

VSN Marketing uses repository-native machine-readable execution state, tasks, checkpoints, architecture records, tests, and CI as the authoritative memory for development. Conversation history is non-authoritative.

Exactly one active task is referenced by `CURRENT-STATE.yaml`. Architecture changes use ADRs. Implementation changes must update the execution ledger/checkpoint in the same change set when applicable.

## Consequences

Any AI model or human developer can resume from Git evidence and the `.ai` ledger. This adds process overhead, but prevents undocumented task jumps, state loss, and architectural drift.
